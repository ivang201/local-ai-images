# Локальная нейросеть для картинок: генерация, редактирование фото и удаление фона

Всё работает **у вас на компьютере**, на видеокарте NVIDIA: без подписок, без интернета (после установки)
и без отправки ваших фото куда-либо.

- **Рисует по тексту на русском:** «рыжий кот спит на подоконнике, за окном дождь» → картинка за ~40 секунд.
- **Меняет ваши фото:** «перенеси меня в Париж к Эйфелевой башне», «замени фон на пляж», «сделай в стиле аниме».
- **Убирает фон → PNG с прозрачностью:** автоматически или по слову — «оставь только кота»,
  «убери провода».
- **Подключается к Claude Code и Codex:** после установки ИИ-помощник сам делает логотипы, иконки и картинки
  для ваших проектов — сгенерирует, вырежет фон и положит файл куда нужно.

Внутри: [FLUX 3 Image Klein](https://huggingface.co/AtomicChat/FLUX-3-Image-Klein-GGUF) через
[stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp), расширитель промптов в
[Ollama](https://ollama.com), [BiRefNet](https://huggingface.co/ZhengPeng7/BiRefNet) и
[SAM 3.1](https://huggingface.co/unsloth/sam3.1) для удаления фона.

---

## Что нужно

| | |
|---|---|
| Система | Windows 10 или 11 (64-бит) |
| Видеокарта | NVIDIA с **8 ГБ** видеопамяти или больше (RTX 3060 Ti / 3070 / 4060 Ti / 4070 и т.п.), свежий драйвер |
| Оперативная память | от 16 ГБ |
| Место на диске | около **27 ГБ** (18 ГБ без удаления фона) |
| Интернет | только на время установки, скачивается ~25 ГБ |

Python и Ollama ставить заранее не нужно — установщик поставит их сам (через `winget`), если их нет.

## Установка под ключ

1. **Скачайте проект:** зелёная кнопка **Code → Download ZIP** вверху этой страницы, распакуйте.
   Или через git: `git clone https://github.com/ivang201/local-ai-images.git`
2. **Положите папку туда, где путь без русских букв и пробелов**, например `C:\ai\local-ai-images`.
   Программа рисования не любит кириллицу в пути.
3. **Дважды кликните `Установить.bat`.** Сначала он спросит, какого ИИ-помощника научить пользоваться
   картинками (подробно — [ниже](#ии-помощник-claude-code-или-codex)):
   ```
   1 — Claude Code
   2 — Codex
   3 — оба
   4 — не нужно
   ```
   После выбора можно уходить — дальше всё само:
   - проверит видеокарту и место на диске;
   - поставит Python и Ollama, если их нет;
   - скачает программу рисования и все модели — ровно тех версий, на которых всё проверено;
   - соберёт окружение для удаления фона;
   - запишет инструкции для выбранного помощника.
4. Подождите: обычно **30–60 минут**, в зависимости от скорости интернета. Если загрузка оборвалась —
   просто запустите `Установить.bat` ещё раз: скачанное он пропустит, недокачанное докачает.

> Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
> Установщик — обычный текстовый скрипт `install.ps1`, его можно открыть Блокнотом и прочитать.

Параметры установщика (`Установить.bat <параметры>` или `powershell -ExecutionPolicy Bypass -File install.ps1 <параметры>`):

| Параметр | Что делает |
|---|---|
| `-Agent claude` / `codex` / `both` / `none` | выбрать помощника без меню |
| `-OnlyInstructions` | ничего не скачивать, только записать инструкции помощнику (сменить выбор, обновить пути) |
| `-SkipRmbg` | не ставить удаление фона (минус ~9 ГБ) |
| `-Yes` | не задавать вопросов; без `-Agent` файлы помощников при этом **не меняются** |

## Как пользоваться

### В браузере

Дважды кликните **`Запустить генератор.bat`** — откроется страница http://127.0.0.1:7860. Окно консоли не
закрывайте, пока пользуетесь.

- **Нарисовать:** напишите, что нужно (можно по-русски), выберите формат, нажмите «Нарисовать» (или Ctrl+Enter).
  Галочка «Улучшать промпт» превращает короткую фразу в подробное описание — с ней картинки заметно лучше.
- **Изменить своё фото:** «+ Фото» (или перетащите фото на страницу, или Ctrl+V), напишите, что изменить.
  До 3 фото сразу. Формат «Как у фото» сохраняет пропорции. Если старый фон «просвечивает» — нажмите ещё раз.
- **Убрать фон:** под любой картинкой — поле «Что оставить» и кнопка «Убрать фон».
  Пусто — останется главный объект; «кот» — только кот; с галочкой «наоборот» — кот станет прозрачным.
  Чтобы убрать фон у своего фото — загрузите его и кликните по миниатюре.
- **Seed** — номер «случайности». Тот же текст + тот же seed = та же картинка. Удобно, чтобы повторить
  удачный вариант и чуть поменять текст.

Все картинки сохраняются в `flux\outputs`, ваши загруженные фото — в `flux\outputs\refs`.

### Из командной строки

```bat
python flux\gen.py "логотип кофейни: лиса и чашка, надпись 'FOX COFFEE', на белом фоне" -o logo.png
python flux\gen.py "горы на рассвете" --aspect 16:9 -n 3
python flux\gen.py "перенеси этого человека в Париж" --ref photo.jpg

rmbg\rmbg.bat photo.jpg                          :: главный объект -> photo_nobg.png
rmbg\rmbg.bat photo.jpg -p "собака"              :: оставить только собак
rmbg\rmbg.bat photo.jpg -p "провода" --remove    :: сделать прозрачными провода
rmbg\rmbg.bat logo.png --crop                    :: вырезать и обрезать по краям
```

`--help` у каждой команды покажет все параметры.

## ИИ-помощник: Claude Code или Codex

ИИ-помощники для программирования читают **файл инструкций** — текст, который они учитывают в каждом чате.
Если дописать туда, как пользоваться генератором и удалением фона, помощник в любом проекте будет сам
делать картинки: «сделай логотип с прозрачным фоном» — и готовый PNG окажется в папке проекта.

| Помощник | Глобальный файл (действует во всех проектах) | Файл одного проекта |
|---|---|---|
| [Claude Code](https://claude.com/claude-code) | `C:\Users\<вы>\.claude\CLAUDE.md` | `CLAUDE.md` в папке проекта |
| [Codex](https://developers.openai.com/codex) (OpenAI) | `C:\Users\<вы>\.codex\AGENTS.md` (или `%CODEX_HOME%\AGENTS.md`) | `AGENTS.md` в папке проекта |

Установщик записывает в глобальный файл — тогда инструкции работают везде.

### Автоматически

В начале установки выберите в меню `1` (Claude Code), `2` (Codex) или `3` (оба). Установщик бережно
обращается с вашим файлом:

- ваш текст не меняется ни на символ — блок **дописывается в конец**, кодировка и переносы строк сохраняются;
- перед записью делается копия: `CLAUDE.md.bak-<дата>` / `AGENTS.md.bak-<дата>` рядом с файлом;
- повторный запуск не дублирует блок, а обновляет его;
- если файла не было — он будет создан.

Передумали или хотите добавить второго помощника — без скачивания:
```bat
Установить.bat -OnlyInstructions
```

### Вручную

1. Откройте `agents\instructions.generated.md` из папки проекта — готовый текст с **вашими** путями
   (его создаёт установщик; шаблон с `{{ROOT}}` вместо пути лежит в `agents\instructions.md`).
2. Откройте Блокнотом нужный файл: Win+R → `notepad %USERPROFILE%\.claude\CLAUDE.md` (Claude Code) или
   `notepad %USERPROFILE%\.codex\AGENTS.md` (Codex) → Enter. Если файла нет — Блокнот предложит создать.
3. Вставьте текст в конец файла и сохраните в кодировке UTF-8.

### Как поменять или убрать

- Всё, что относится к этому проекту, находится между строками `<!-- local-ai-images:start -->` и
  `<!-- local-ai-images:end -->`. Этот кусок можно править прямо в Блокноте: поменять рецепты, убрать
  ненужный инструмент. Чтобы отключить — удалите блок целиком вместе с этими двумя строками.
- Можно попросить самого помощника: «поменяй в глобальном CLAUDE.md …» / «… в глобальном AGENTS.md …».
- Изменения действуют **в новых чатах** — уже открытый чат прочитал старую версию.
- Перенесли папку проекта — запустите `Установить.bat -OnlyInstructions`: пути в блоке обновятся.
- Если что-то пошло не так — верните копию `.bak`: переименуйте её обратно в `CLAUDE.md` / `AGENTS.md`.

### Проверка

Откройте **новый** чат и попросите: «сделай логотип кофейни с лисой на прозрачном фоне и положи в папку
проекта». Помощник сам вызовет генератор, вырежет фон и сохранит PNG.

> **Codex:** команды запускаются в песочнице. Генератору нужна видеокарта и локальный адрес
> `127.0.0.1` (Ollama), поэтому при первом запуске разрешите Codex выполнить команду, когда он спросит.

## Скорость (RTX 3060 Ti, 8 ГБ)

| Что | Время |
|---|---|
| Картинка 1024×1024 | 35–45 с (с улучшением промпта 45–80 с) |
| Изменение фото | 60–90 с |
| Удаление фона | 10–15 с |

Первая генерация после запуска дольше — модели загружаются с диска.

## Если что-то не так

- **Не скачивается с GitHub** (бывает с VPN/прокси): скачайте вручную два файла со страницы
  [релиза stable-diffusion.cpp master-1060](https://github.com/leejet/stable-diffusion.cpp/releases/tag/master-1060-0b3b98d) —
  `sd-master-0b3b98d-bin-win-cuda12-x64.zip` (переименуйте в `sd-cuda.zip`) и
  `cudart-sd-bin-win-cu12-x64.zip` (в `cudart.zip`), положите в `flux\sd\` и запустите установщик снова.
- **Не хватает видеопамяти / очень медленно:** закройте игры и программы, которые используют видеокарту
  (браузер с видео тоже). Не запускайте генерацию и удаление фона одновременно.
- **Русские буквы на картинке выходят латиницей** («РАМЕН» → «PAMEH») — это ограничение модели. Надписи пишите
  по-английски в кавычках: `вывеска "RAMEN"`.
- **«Ollama не запустилась»** — откройте приложение Ollama из меню «Пуск» и попробуйте снова.
- **Удаление фона не находит объект** — назовите проще («car» вместо «моя машинка»).

## Как удалить

1. Удалите папку проекта.
2. В командной строке: `ollama rm hf.co/AtomicChat/FLUX-3-Image-Klein-pup-Uncensored-GGUF:IQ4_XS`
3. Уберите блок `local-ai-images` из `CLAUDE.md` / `AGENTS.md` (см. выше).
